"أنجولار بتستخدم تقنية اسمها View Encapsulation لعزل الـ CSS الخاص بكل Component ومنعه إنه يغير شكل باقي الموقع.

:host: بستخدمها عشان أدي تنسيق للكومبوننت نفسه كـ Tag خارجي (Host Element).

::ng-deep: بستخدمها عشان أكسر عزل أنجولار وأوصل للعناصر الداخلية الخاصة بـ Child Components أو مكتبات خارجية زي PrimeNG.

Best Practice: دايماً بدمجهم مع بعض كـ :host ::ng-deep عشان الـ CSS يطبق على المكتبة جوه الكومبوننت ده بس وما يتسربش لباقي المشروعات."

==============================================
:host
المفهوم: بيستهدف الـ Tag الخارجي بتاع الكومبوننت نفسه.

مثال: لو الكومبوننت بتاعك اسمه <app-user-card>:

CSS
/* التنسيق ده هيتطبق على <app-user-card> نفسه */
:host {
  display: block;
  border: 1px solid #ccc;
  border-radius: 8px;
}
===============================================
::ng-deep
المفهوم: المطرقة اللي بتكسر حماية أنجولار للتعديل على مكتبات خارجية (زي PrimeNG).

مثال: التعديل على زرار جوه PrimeNG:

CSS
/* التعديل هيطبق على p-button اللي جوه الكومبوننت بتاعك بس */
:host ::ng-deep .p-button {
  background-color: #284980 !important;
}
